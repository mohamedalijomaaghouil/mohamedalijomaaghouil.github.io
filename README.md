# Mohamed Ali Jomaa Ghouil · Robotics Portfolio

Personal portfolio: robotics & mechatronics engineering student (SIGMA Clermont × ENISo), looking for a 6-month end-of-studies internship from 7 March 2027.

**Live:** https://mohamedalijomaaghouil.github.io

## Stack

Plain static site, no build step: one `index.html` (inline CSS + vanilla JS) and `assets/`.

- `assets/img/` photos, max 1400 px, JPEG q78, metadata stripped
- `assets/video/` H.264 720p with faststart; `*-loop.mp4` are short muted previews that only load when the card scrolls into view
- `assets/docs/` CV and certificates

## Run locally

```bash
python3 -m http.server 8000
# open http://localhost:8000
```
